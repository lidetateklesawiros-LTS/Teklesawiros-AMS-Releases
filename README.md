# Teklesawiros AMS Android App Releases
Official release APKs for the Teklesawiros Sunday School Attendance Management System.

## Latest Release: v3.0.0 (Build 12)
- Post-Session Quick Summary Report: Real-time attendance summary popup on session completion/manual finish showing total present, males, females, absents, Ethiopian date, and department; clean cancellation notice without saving.
- Large Full-Screen Viewfinder (Image-18): Expanded scanning viewfinder with 4 white illuminated brackets, animated green laser scan line, helper text, and circular light/torch toggle button.
- Full-Page Manual Checklist: Scrollable full-page student roster for taking attendance manually.
- Late Comers Permission Form: Register late arrivals within 30 minutes after session end with reason notes.
- Database Backup & Restore: Admin can export full Firestore collections to JSON and restore from backup files directly in the app.
- Animated Sliding Titles (Marquee): Modern animated sliding banners in Login, Dashboard, and Web App.
- Web App Multi-Date Reports: Export attendance across multiple days, full months, or years to Excel and PDF.
- Web App Security Audit: Logs capture client IP, device OS, and browser details.
- Pure Ethiopian Calendar: Pure Ethiopian dates in Attendance History without Gregorian equivalent text.
- Department Dashboard View: Instant toggle to filter overview analytics by department.
- Full English Language Support: Complete toggle across all sections, tables, and dialogs.
